### Prepare the website

The documentation site is built using [Docusaurus](https://docusaurus.io) and
published on the project
[GitHub Pages](https://xpack-dev-tools.github.io/openocd-xpack/).

- Switch to the `xpack-development` branch
- Execute the **website-generate-commons** npm script in the `website/package.json`
  ```sh
  npm --prefix ~/Work/xpack-dev-tools/openocd-xpack.git/website run website-generate-commons
  ```
- **Commit** all changes
