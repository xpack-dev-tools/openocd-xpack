## Obtain project sources

The project is hosted on GitHub:

- https://github.com/xpack-dev-tools/openocd-xpack.git

<BranchesDetails />

To clone the stable branch (`xpack`), execute the following commands in a
terminal (on Windows use the _Git Bash_ console):

```sh
rm -rf ~/Work/xpack-dev-tools/openocd-xpack.git && \
mkdir -p ~/Work/xpack-dev-tools && \
git clone \
  --branch xpack \
  https://github.com/xpack-dev-tools/openocd-xpack.git \
  ~/Work/xpack-dev-tools/openocd-xpack.git
```

<details>
<summary>For development purposes, clone the `xpack-development` branch.</summary>

```sh
rm -rf ~/Work/xpack-dev-tools/openocd-xpack.git && \
mkdir -p ~/Work/xpack-dev-tools && \
git clone \
  --branch xpack-development \
  https://github.com/xpack-dev-tools/openocd-xpack.git \
  ~/Work/xpack-dev-tools/openocd-xpack.git
```

</details>

Alternatively, if the repository has already been cloned:

```sh
git -C ~/Work/xpack-dev-tools/openocd-xpack.git pull
```

:::tip

To contribute Pull Requests, fork the project and ensure the **Copy the master branch only** is **disabled**.

Utilise the `xpack-development` branch and ensure you contribute the
Pull Requests back to the `xpack-development` branch.

:::

## Add links for development

During development, it is convenient to maintain a writable instance of the
library to enable changes in parallel with the parent project.

To facilitate the use of a writable instance of this library in other
projects, add a link from the user's global xPacks store to this local
development folder:

```sh
xpm link -C ~/Work/xpack-dev-tools/openocd-xpack.git
```

And in the projects referring it:

```sh
xpm link @xpack-dev-tools/openocd
```
