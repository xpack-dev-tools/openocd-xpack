### Start the local web server

Execute the npm script **clear** followed by **start** in the website sub-project,
or execute the following within the project folder:

```sh
npm --prefix ~/Work/xpack-dev-tools/openocd-xpack.git/website run clear
npm --prefix ~/Work/xpack-dev-tools/openocd-xpack.git/website run start
```

Navigate to the **Maintainer Info** page,
the **[Start the local web server](http://localhost:3000/openocd-xpack/docs/maintainer/#start-the-local-web-server)** section.
