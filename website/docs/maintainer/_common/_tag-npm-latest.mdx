### Check npm package tags

Execute the following command in a terminal:

```sh
npm dist-tag ls @xpack-dev-tools/openocd
```

### Tag the npm package as `latest`

When the release is considered stable, promote it as `latest`:

<CodeBlock language="sh"> {
`npm dist-tag add @xpack-dev-tools/openocd@0.12.0-7.1 latest
`} </CodeBlock>

Check the result:

<CodeBlock language="sh"> {
`npm dist-tag ls @xpack-dev-tools/openocd
`} </CodeBlock>

Should the release prove problematic and require unpublishing:

<CodeBlock language="sh"> {
`npm unpublish @xpack-dev-tools/openocd@0.12.0-7.1
`} </CodeBlock>
